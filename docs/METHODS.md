# Methods and source definitions

This project analyzes published isolate-level annotations accompanying Matuszewska, Murray et al. (2022), *eLife* 11:e74819 (DOI: [10.7554/eLife.74819](https://doi.org/10.7554/eLife.74819)).

The supplementary workbooks are independently retrievable from the original publisher. The notebook records source SHA-256 checksums and explicit column mappings.

The 1,180 CC398 records are joined by Strain identifier. Two zero-padding inconsistencies, \`07-1 / 7-1\` and \`07-3 / 7-3\`, are normalized and logged. The reconstructed cohort includes 704 LA and 476 HA clade assignments. These are evolutionary clades rather than the sampled host categories.

For each binary annotation the reported denominator is the number of nonmissing observations in that clade. All features in the published summary exports have complete binary calls. The eight-gene and mobile-element figures summarize the 1,180-isolate cohort; the separate 1,178-isolate historical comparison establishes what was shown in the earlier analysis.

Eight unadjusted two-sided Fisher exact tests are used for descriptive comparison only. They ignore phylogenetic nonindependence, so cannot establish repeated acquisitions, independent host adaptation, or causality. The article's independent phylogenetic grouping and McNemar analysis are not reproduced here.

**Annotation caveats.** Supplementary File 3 records \`Sa3=1\` for 109/704 LA isolates. The manuscript reports 68/704 LA isolates carrying a φSa3 prophage. These values should not be equated without resolving the different annotation criteria. Supplementary files 3 and 7 disagree on five \`mecA\` calls; the plotted \`mecA\` gene prevalence uses the File 3 annotation, as explained in the notebook.

For the original publisher data accessions and per-file provenance, see [the source manifest](../results/input_manifest.csv). No raw reads or new isolate sequences were generated by this analysis.
